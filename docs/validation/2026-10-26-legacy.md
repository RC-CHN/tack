# 统一客户端 Legacy 兼容验证 — 2026-10-26

基于 `b552402` 后的未提交工作区，测试版本 `0.0.0-ci`。同一个客户程序同时包含命令执行与 Chisel 客户端；本轮增加 Go 1.23.12 的 Linux 兼容构建、外部选包路径、依赖来源校验和最终产物门禁。没有创建发布标签、推送或发布。以下为本地验证结果，托管 CI 尚未执行这批修改。

两个文件均关闭 CGO、没有 race 插桩，能力记录均包含 `management`、`embedded-chisel`。本机 5 个归档（两种 Node、Controller、CLI、Chisel）完整性、目标格式、版本执行与记录一致性全部通过；验证器分别提取两种 Node，没有相互覆盖。Modern 文件与前一轮统一客户端验证的哈希相同，其资源结果仍可追溯。

另外构建并校验了完整的 **10 个 Legacy Linux 混淆归档**：amd64、386、ARMv5/v6/v7、arm64、MIPS/MIPSel/MIPS64/MIPS64el softfloat。Windows Modern amd64/386/arm64 普通交叉编译通过。非本机架构没有执行；本轮未重新构建完整 46 个正式发布归档，也没有进行 Windows 原生测试。

## 真实旧内核功能

使用 QEMU system x86 TCG，384 MiB 内存、2 个虚拟 CPU，启动 CentOS 6.10 的 `2.6.32-754.el6.x86_64` 内核及 BusyBox musl initramfs。下载来源和 SHA-256 固定在 `compat/legacy/vm-fixtures.json`；RPM 及解出的内核、网卡模块分别校验。虚拟机网络限制为两个显式本机 TLS 转发端点。

最终 Legacy 混淆文件在该内核中完成：

- 校验证书与 SSH 指纹的连接及 64 KiB 反向隧道回显，逐字节核对。
- 通过控制平面执行一项 POSIX shell 任务，返回真实 `uname -r`，并确认 shell 的父进程可执行文件为 `/tack-node`。
- SIGTERM 后以 0 退出，默认诊断日志为 0 B。

这使用真实旧内核，但不是完整 CentOS 用户空间，也没有验证 vendor init、NAS 卷、闪存/overlay、持久盘或重启后的服务恢复。

此前的对照探测观察到：未加壳 Go 1.23 统一文件能够启动；UPX 5.0.2 处理的 Go 1.23 和现代 Go 文件均以 139 退出。故不能沿用现代宿主机上 UPX 自检/启动成功的结论。Legacy 发布策略明确保留 Garble、跳过 UPX，在 `BUILD.json` 记录例外；原始失败记录保留。未宣称所有旧内核或所有 packer 都存在同一缺陷。

## 回归、构建与维护边界

- Modern 与 Legacy 根模块全部 race 测试、vet 通过；Legacy 使用 `-mod=readonly -modfile=go.legacy.mod`，无需临时修改依赖文件。
- 适配后的上游 SSH、chacha20、curve25519、poly1305 race 回归通过，保留当前 SSH 释放/关闭修复；生成目录的所有文件与适配 manifest 哈希一致。
- Python 15 项脚本测试通过，覆盖选包边界、重复/缺失候选、只含管理能力的旧包拒绝、校验失败不得执行、两种 Node 的提取与保护要求。
- 工作流 actionlint、fixture 覆盖检查、部署 skill 校验和文档链接检查通过。新增 CI 门禁使用同一个本地已经通过的 `qualify-legacy.py`，并在创建 draft 前复验最终归档。

Legacy 限于 Linux；Windows 10 / Server 2016 起，不承诺 Win7/8。ARM/MIPS 的编译结果不等于真机认证。Go 1.23 的标准库已停止官方常规维护，当前 SSH 适配并非完整安全维护替代；Legacy 明确不包含 SSH ML-KEM、FIPS 或浏览器 TLS profile。部署与持久化仍完全位于外部 skill，不能把同版本运行时替换误认为可任意降级状态格式。

按仓库约定只保留本摘要。原始 JSON/log、构建/适配 manifest、归档校验值及 UPX 失败探测存于忽略目录 `management/validation/2026-10-26-legacy/`，最终门禁位于其中的 `final/`。本机归档的源快照 SHA-256 为 `a9708e6f58bbadf3b2108b1eac7df61f7c936c767b30ab34fdc0254b8a46127b`；构建后补充了测试/文档，编译的 Go 源码未变化。操作步骤见[兼容说明](../legacy-compatibility.md)。
